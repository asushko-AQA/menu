# Закупки на 4-ю неделю

Список продуктов на семью **5 человек** по меню [Меню на 4-ю неделю](nedelya-4.md). Обеды: томатно-фасолевый суп с индейкой (Пн–Ср), сырный суп с курицей (Чт–Сб); воскресенье — пицца на лаваше с индейкой. Молочное — только **БЛ**. Количества рассчитаны автоматически по карточкам блюд (`node scripts/build-shopping.js`), округлены до удобных для покупки; суп и печенье на несколько дней учтены один раз.
