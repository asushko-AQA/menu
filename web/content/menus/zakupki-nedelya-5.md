# Закупки на 5-ю неделю

Список продуктов на семью **5 человек** по меню [Меню на 5-ю неделю](nedelya-5.md). Обеды: чечевичный суп с овощами (Пн–Ср), щи из капусты (Чт–Сб); воскресенье — мини-бургеры из индейки. Молочное — только **БЛ**. Количества рассчитаны автоматически по карточкам блюд (`node scripts/build-shopping.js`), округлены до удобных для покупки; суп и печенье на несколько дней учтены один раз.
