# Закупки на 1-ю неделю

Список продуктов на семью **5 человек** по меню [Меню на 1-ю неделю](nedelya-1.md). Обеды: гороховый суп (Пн–Ср), тыквенный суп-пюре (Чт–Сб); воскресенье — домашняя шаурма-ролл. Молочное — только **БЛ**. Количества рассчитаны автоматически по карточкам блюд (`node scripts/build-shopping.js`), округлены до удобных для покупки; суп и печенье на несколько дней учтены один раз.
