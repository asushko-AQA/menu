# Мясной рулет с яйцом «сюрприз» и пюре

Рулет из фарша с варёными яйцами внутри — на срезе яйца выглядят красиво, дети в восторге. С картофельным пюре — основательный выходной ужин.

## Ингредиенты (на 5 человек)

| Продукт | Количество |
|---------|------------|
| Фарш свино-говяжий | 700 г |
| Яйца (1 в фарш + 4 вкрутую внутрь) | 5 шт. |
| Лук репчатый | 1 шт. (100 г) |
| Хлеб белый (батон) | 60 г |
| Молоко БЛ (размочить хлеб) | 80 мл |
| Картофель | 1 кг |
| Молоко БЛ (для пюре) | 120 мл |
| Масло сливочное БЛ | 30 г |
| Зелень | 15 г |
| Соль | 2 ч. л. (12 г) |

## Специи и приправы

- Соль, чёрный перец — щепотка. Зелень, паприка 0,5 ч. л. — по желанию.

## Приготовление

1. Яйца (4 шт.) сварить вкрутую (10 мин), остудить, очистить. Хлеб размочить в молоке БЛ.
2. Фарш смешать с мелко нарубленным луком, размоченным хлебом, сырым яйцом и 1,5 ч. л. соли, вымесить.
3. Фарш выложить на пергамент в прямоугольник 20×25 см, толщиной ~2 см. Вдоль выложить ряд яиц, свернуть рулетом с помощью пергамента, края защипнуть.
4. Выложить рулет швом вниз на противень, запекать при 190 °C 45–50 мин, поливая выделившимся соком. Картофель сварить (20 мин), размять с горячим молоком, маслом и 0,5 ч. л. соли.
5. Дать рулету отдохнуть 10 мин, нарезать ломтями. Подавать с пюре.

## Подготовка заранее

- Яйца сварить заранее (с вечера); сформировать рулет с утра и убрать в холодильник до запекания.

## Состав по компонентам

- **Основа:** мясной фарш, яйца.
- **Гарнир:** картофельное пюре.

## Порции и время

- На 5 человек (8–10 ломтей). ~30 мин работы + ~50 мин в духовке (~80 мин; для выходного дня).
- **Белок (оценка):** ≈ 190 г на семью за приём; ≈ 38 г на среднего члена семьи. Оценка по таблице ингредиентов (сырой вес).

## Аллергены и особенности

- Яйца, глютен (хлеб), молочное — только БЛ.

## Подача

- Горячим, ломтями с пюре. На срезе — «сюрприз» из яйца. Хорош холодным в бутерброд на следующий день.
