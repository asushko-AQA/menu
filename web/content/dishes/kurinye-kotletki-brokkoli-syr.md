# Куриные котлетки с брокколи и сыром

Сочные запечённые котлетки из куриного филе с мелко нарубленной брокколи и сыром БЛ. Зелени не видно, а вкус сырный — овощи съедаются незаметно. Подаются с рисом.

## Ингредиенты (на 5 человек)

| Продукт | Количество |
|---------|------------|
| Куриное филе | 600 г |
| Брокколи | 300 г |
| Сыр БЛ тёртый | 100 г |
| Яйцо | 1 шт. |
| Овсяные хлопья (измельчить в муку) | 40 г |
| Чеснок | 1 зубчик (5 г) |
| Масло растительное | 2 ст. л. (30 мл) |
| Рис длиннозерный | 250 г (сухой вес) |
| Соль | 1 ч. л. (6 г) |

## Специи и приправы

- Соль, чёрный перец — щепотка. Чеснок — по желанию.

## Приготовление

1. Брокколи разобрать на соцветия, отварить 3 мин в кипящей воде, остудить, мелко порубить. Духовку разогреть до 190 °C.
2. Филе провернуть через мясорубку или измельчить блендером (не в пюре — оставить мелкие кусочки). Смешать с брокколи, сыром, яйцом, овсяной мукой, чесноком и солью.
3. Сформировать 12–14 котлет, выложить на смазанный маслом противень. Запекать 20–22 мин, перевернув на середине.
4. Рис отварить по упаковке. Подавать котлетки с рисом.

## Подготовка заранее

- С вечера отварить и порубить брокколи, измельчить филе — утром только смешать и сформировать.

## Состав по компонентам

- **Основа:** куриное филе, брокколи.
- **Сыр:** БЛ.
- **Гарнир:** рис.

## Порции и время

- На 5 человек (12–14 котлет). ~40 мин.
- **Белок (оценка):** ≈ 190 г на семью за приём; ≈ 38 г на среднего члена семьи. Оценка по таблице ингредиентов (сырой вес).

## Аллергены и особенности

- Яйцо, глютен (овёс), молочное — только БЛ.

## Подача

- Горячими, по 2–3 штуки с рисом. Малышам — котлетки поменьше.
