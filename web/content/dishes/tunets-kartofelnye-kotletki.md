# Тунцовые котлетки с картофелем и йогуртовым соусом

Нежные котлетки из консервированного тунца, картофельного пюре и укропа. Жарятся быстро или запекаются в духовке. Недорогой способ накормить детей рыбой.

## Ингредиенты (на 5 человек)

| Продукт | Количество |
|---------|------------|
| Тунец консервированный в собственном соку | 2 банки (нетто всего 320–400 г) |
| Картофель | 800 г |
| Яйца | 2 шт. |
| Лук репчатый (натереть) | 0,5 шт. (50 г) |
| Сухари панировочные (в массу) | 60 г |
| Сухари панировочные (для обвалки) | 40 г |
| Укроп | 15 г |
| Масло растительное для жарки | 40 мл |
| Соль | 0,5–1 ч. л. (3–6 г) |
| Йогурт БЛ густой с огурцом (подача) | 150 г |
| Огурцы (подача) | 2 шт. (200 г) |

## Специи и приправы

- Соль, чёрный перец — щепотка, укроп.

## Приготовление

1. Картофель сварить в подсоленной воде 20 мин, слить воду, размять в пюре и слегка остудить.
2. Тунец размять вилкой (рассол слить). Смешать с пюре, яйцами, луком, сухарями (60 г), укропом и солью.
3. Сформировать 14–16 котлеток, обвалять в сухарях. Жарить на масле по 3 мин с каждой стороны (или запекать 15 мин при 200 °C).
4. Подавать с йогуртовым соусом (густой йогурт с мелко нарезанным огурцом) и огурцами.

## Подготовка заранее

- Картофель можно сварить с вечера (остатки пюре подойдут).

## Состав по компонентам

- **Основа:** тунец, картофель.
- **Панировка:** сухари.
- **Соус:** йогурт БЛ с огурцом.

## Порции и время

- На 5 человек (14–16 котлеток). ~35 мин.
- **Белок (оценка):** ≈ 141 г на семью за приём; ≈ 28 г на среднего члена семьи. Оценка по таблице ингредиентов (сырой вес).

## Аллергены и особенности

- Рыба, яйца, глютен (сухари). Молочное — только БЛ йогурт.

## Подача

- Горячими, с соусом. Детям — маленькие котлетки.
