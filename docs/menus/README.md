# Меню по неделям

Единая точка входа: выбор недели и переход к сетке завтрак + обед + полдник + ужин по дням. В каждой неделе внизу — **оценка белка по дням**.

|--------|------|-------------|-----------------|

| 2 | [nedelya-2.md](nedelya-2.md) | борщ с фасолью / куриный суп с лапшой | кесадилья |
| 3 | [nedelya-3.md](nedelya-3.md) | рыбный суп / суп с фрикадельками | тако-конструктор |
| 4 | [nedelya-4.md](nedelya-4.md) | томатно-фасолевый суп с индейкой / сырный суп с курицей | пицца на лаваше |
| 5 | [nedelya-5.md](nedelya-5.md) | чечевичный суп с курицей / щи | мини-бургеры из индейки |
