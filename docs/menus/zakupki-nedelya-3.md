# Закупки на 3-ю неделю

Список продуктов на семью **5 человек** по меню [Меню на 3-ю неделю](nedelya-3.md). Обеды: рыбный суп (Пн–Ср), суп с фрикадельками (Чт–Сб); воскресенье — тако-конструктор. Молочное — только **БЛ**. Количества рассчитаны автоматически по карточкам блюд (`node scripts/build-shopping.js`), округлены до удобных для покупки; суп и печенье на несколько дней учтены один раз.
