# Кесадилья с курицей, кукурузой и сыром

Тонкая лепёшка, сложенная пополам, с куриным филе, кукурузой, помидором и расплавленным сыром БЛ. Жарится на сухой сковороде за 3–4 минуты. Подаётся с йогуртовым соусом.

## Ингредиенты (на 5 человек)

| Продукт | Количество |
|---------|------------|
| Куриное филе | 400 г |
| Лаваш тонкий | 4 листа (≈ 320 г) |
| Сыр БЛ тёртый | 120 г |
| Кукуруза консервированная | 150 г |
| Помидоры | 2 шт. (200 г) |
| Перец сладкий | 1 шт. (100 г) |
| Йогурт БЛ густой (соус) | 200 г |
| Масло растительное | 2 ст. л. (30 мл) |
| Зелень | 15 г |
| Соль | 0,5–1 ч. л. (3–6 г) |

## Специи и приправы

- Паприка сладкая 1 ч. л., соль. Острый соус — только взрослым отдельно.

## Приготовление

1. Филе нарезать мелкими кубиками, обжарить на 1 ст. л. масла с паприкой и солью 7–8 мин. Помидоры и перец нарезать мелким кубиком.
2. Смешать курицу с кукурузой, помидорами и перцем.
3. Лист лаваша сложить пополам, на половину выложить начинку и сыр, накрыть второй половинкой.
4. Жарить на сухой (или слегка смазанной) сковороде по 1,5–2 мин с каждой стороны до румяной корочки и расплавившегося сыра. Нарезать секторами. Соус — йогурт с зеленью.

## Подготовка заранее

- С вечера: обжарить курицу, нарезать овощи, натереть сыр. Сборка — 10 мин.

## Состав по компонентам

- **Основа:** лаваш, курица, сыр БЛ.
- **Начинка:** кукуруза, помидор, перец.
- **Соус:** густой йогурт БЛ с зеленью.

## Порции и время

- На 5 человек (4 кесадильи, по 8 секторов). ~30 мин.
- **Белок (оценка):** ≈ 161 г на семью за приём; ≈ 32 г на среднего члена семьи. Оценка по таблице ингредиентов (сырой вес).

## Аллергены и особенности

- Глютен (лаваш), молочное — только БЛ. Без яиц.

## Подача

- Горячей, секторами; соус рядом. Малышам — без перца, секторы поменьше.
