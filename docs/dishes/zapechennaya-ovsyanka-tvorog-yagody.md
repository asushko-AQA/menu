# Запечённая овсянка с творогом и ягодами

Нежная запеканка из овсяных хлопьев, творога БЛ и банана с ягодами внутри. Нарезается порционными квадратиками — можно есть руками. Сладость только от банана и ягод.

## Ингредиенты (на 5 человек)

| Продукт | Количество |
|---------|------------|
| Овсяные хлопья (не быстрого приготовления) | 250 г |
| Творог БЛ | 300 г |
| Яйца | 2 шт. |
| Молоко БЛ | 300 мл |
| Бананы спелые | 2 шт. (260 г) |
| Ягоды замороженные (малина, черника, вишня без косточки) | 250 г |
| Разрыхлитель | 1 ч. л. (4 г) |
| Масло для формы | 10 г |
| Корица | 0,5 ч. л. |

## Специи и приправы

- Корица. Ванилин — на кончике ножа (по желанию).

## Приготовление

1. Бананы размять вилкой. Смешать с яйцами, молоком и творогом (творог можно слегка протереть).
2. Добавить хлопья, разрыхлитель и корицу, перемешать. Дать постоять 5–10 мин, чтобы хлопья набухли.
3. Форму 20×30 см смазать, выложить массу, сверху распределить ягоды (не размораживать). Запекать при 180 °C 30–35 мин до золотистого верха.
4. Остудить 5 мин, нарезать квадратами. Подавать тёплой или холодной.

## Подготовка заранее

- С вечера смешать всё, кроме разрыхлителя и ягод, убрать в холодильник (хлопья как раз набухнут). Утром — добавить разрыхлитель и ягоды, запекать 30–35 мин.

## Состав по компонентам

- **Основа:** хлопья, творог БЛ, яйца, молоко БЛ.
- **Подслащивание:** бананы, ягоды.

## Порции и время

- На 5 человек (~10 квадратов). ~10 мин работы + 30–35 мин в духовке.
- **Белок (оценка):** ≈ 110 г на семью за приём; ≈ 22 г на среднего члена семьи. Оценка по таблице ингредиентов (сырой вес).

## Аллергены и особенности

- Яйца, глютен (овёс), молочное — только БЛ. Без добавленного сахара.

## Подача

- Квадрат тёплой запеканки; сверху ложка густого йогурта БЛ — по желанию.
