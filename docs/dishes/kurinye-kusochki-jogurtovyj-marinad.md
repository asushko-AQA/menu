# Куриные кусочки в йогуртовом маринаде с рисом

Куриные бёдра без кости в нежном йогуртово-лимонном маринаде с паприкой и куркумой запекаются сочными золотистыми кусочками. Подаются с рисом и свежим салатом.

## Ингредиенты (на 5 человек)

| Продукт | Количество |
|---------|------------|
| Куриные бёдра без кости (или филе) | 750 г |
| Йогурт БЛ натуральный | 150 г |
| Лимон | 0,5 шт. (50 г) |
| Чеснок | 2 зубчика (10 г) |
| Масло растительное | 2 ст. л. (30 мл) |
| Рис длиннозерный | 250 г (сухой вес) |
| Огурцы | 2 шт. (200 г) |
| Помидоры | 2 шт. (200 г) |
| Соль | 1 ч. л. (6 г) |

## Специи и приправы

- Паприка сладкая 1 ч. л., куркума 0,5 ч. л., соль, чёрный перец — щепотка.

## Приготовление

1. Мясо нарезать кусочками 3–4 см. Смешать йогурт, сок половины лимона, чеснок, масло, паприку, куркуму, соль. Залить курицу и оставить минимум на 30 мин (можно с вечера).
2. Духовку разогреть до 200 °C. Курицу выложить на противень в один слой, запекать 20–25 мин, на середине перевернуть.
3. Рис отварить по упаковке (15–18 мин). Овощи нарезать для салата.
4. Подавать курицу с рисом и салатом.

## Подготовка заранее

- С вечера замариновать курицу — к ужину она станет мягче и ароматнее; рис можно отварить заранее.

## Состав по компонентам

- **Основа:** курица, йогуртовый маринад.
- **Гарнир:** рис.
- **Овощи:** огурцы, помидоры.

## Порции и время

- На 5 человек. ~40 мин активно (+ маринование от 30 мин).
- **Белок (оценка):** ≈ 187 г на семью за приём; ≈ 37 г на среднего члена семьи. Оценка по таблице ингредиентов (сырой вес).

## Аллергены и особенности

- Молочное — только БЛ. Без глютена и яиц.

## Подача

- Горячим. Кусочки на шпажки не нанизывать (малышам).
