# Тыквенный суп-пюре с курицей и сырными гренками

Яркий нежный суп-пюре из тыквы и картофеля с кусочками курицы. Сырные гренки при подаче делают суп «праздничным» — и добавляют белка.

## Ингредиенты (на 15 порций — 5 чел. × 3 дня)

| Продукт | Количество |
|---------|------------|
| Тыква (очищенная) | 1,2 кг |
| Картофель | 400 г |
| Морковь | 250 г |
| Лук репчатый | 250 г |
| Куриное филе | 900 г |
| Сливки БЛ | 300 мл |
| Масло растительное | 2 ст. л. (30 мл) |
| Вода | 2,5–3 л |
| Соль | 2–3 ч. л. (12–18 г) |
| Сыр БЛ тёртый для гренок (подача, на один обед) | 50 г |
| Хлеб для гренок (подача, на один обед) | 80 г |

## Специи и приправы

- Соль, мускатный орех — щепотка (по желанию), чёрный перец — щепотка.

## Приготовление

1. Филе варить в подсоленной воде 20 мин, вынуть, разделить на мелкие волокна или нарезать кубиками 1 см.
2. Тыкву, картофель, морковь и лук нарезать, обжарить лук и морковь на масле 5 мин, добавить тыкву и картофель, залить 2 л воды (или бульоном от курицы), варить 20 мин до мягкости.
3. Взбить суп погружным блендером до однородности, влить сливки, довести до слабого кипения. Посолить.
4. Добавить курицу, прогреть 3 мин. Для гренок: хлеб нарезать кубиками, посыпать сыром, подсушить 5 мин при 200 °C. Подавать суп с гренками.

## Подготовка заранее

- Тыкву можно заранее очистить, нарезать и заморозить кубиками. Гренки — свежими на каждый обед.

## Состав по компонентам

- **Основа:** тыква, картофель, морковь.
- **Белок:** курица, сливки БЛ.
- **Подача:** сырные гренки.

## Порции и время

- На 15 порций (5 человек × 3 дня). ~50 мин. Порция: 300–350 мл взрослым, 150–200 мл малышам.
- **Белок (оценка):** ≈ 93 г на семью за приём (за одну порцию-приём: блюдо на несколько дней); ≈ 19 г на среднего члена семьи. Оценка по таблице ингредиентов (сырой вес).

## Аллергены и особенности

- Молочное — только БЛ, глютен (гренки). Без яиц.

## Подача

- Горячим, с сырными гренками. Курица остаётся мягкими кусочками — малышам удобно.
